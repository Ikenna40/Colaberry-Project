8. Appendix

Where everything actually runs, plus a glossary of every jargon term used across this site.

What runs where

Four of the ten rows run on somebody else's servers — worth remembering that client engagement and satisfaction data leaves Colaberry's own infrastructure each night to reach Claude, and is pulled in from three different vendors.

Glossary

TermPlain-English meaning
APIA standard way for two systems to exchange data over the web.
SDKA ready-made code library, so you don't build the plumbing to talk to a service yourself.
VPSA rented server you have full control over, running Colaberry's own software.
CSV exportA spreadsheet-style data file, downloaded on a schedule instead of pulled live.
Rate limitingA service capping how many requests you can make per minute before it blocks you.
LLMAn AI language model — the kind of model behind Claude — that reads and writes plain text.
Model tiersFaster/cheaper vs. smarter/pricier versions of the same AI model family.
CI/CDAutomatically testing and shipping code changes, rather than doing it by hand every time.
