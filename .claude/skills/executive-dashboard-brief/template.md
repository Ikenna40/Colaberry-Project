# Executive Dashboard Brief — Template

Use this exact structure. Do not add, remove, or reorder sections. Do not fill any field with an invented value — if the source report doesn't state it, mark the field as not yet determined rather than guessing.

## Status
[One line — e.g. "Blocked," "Delayed," "Resolved," "At Risk." Must match the source report's own PASS/WARN/FAIL or PUBLISH/BLOCK conclusion exactly; do not soften or reverse it.]

## Business Impact
[Plain-language description of what this means for the business — which report, dashboard, or decision is affected, and how. State a dollar or numeric impact only if the source report actually quantifies one; otherwise write "Not yet quantified."]

## What We Know
[Bullet list of verified facts, each traceable to something the source report(s) actually state. No speculation in this section.]

## What We Do Not Know
[Bullet list of open questions the source report(s) left unresolved. Do not leave this empty just to look tidy — if something is genuinely unknown, say so here.]

## Decision or Action Needed
[The specific decision or action leadership needs to take or approve now — not a general status restatement. If no decision is needed yet, say so explicitly.]

## Owner
[Name or team accountable for resolution, only if the source report(s) name one. Otherwise: "Not yet assigned."]

## Next Update
[Specific date/time the next update will be provided, only if stated in the source. Otherwise: "Not yet scheduled."]
