Technical evidence (log & run metadata citations)
  • Most probable cause: the region-mapping step has no entry for a blank/missing region value — evidenced by an identical KeyError at order_id=ORD-1005 across all 4 attempts (orders-pipeline-failure.log, lines 9, 18, 24, 30).
  • Run metadata states the region_lookup table "has no entry for null/empty region values and no configured default fallback."
  • Schema validation logged the mismatch as a warning (not an error) and let it proceed, which is why the row reached the mapper (log lines 5–7).
  • Not yet confirmed: whether non-standard region strings (West/East/South/North) would also fail to map — the pipeline never processed past this row in any attempt.
