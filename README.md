# Colaberry Project

Governance foundation for this repository. Full operating rules for AI coding agents live in [CLAUDE.md](./CLAUDE.md) — read that first, before anything else.

- [ARCHITECTURE.md](./ARCHITECTURE.md) — the approved folder-tree architecture: what exists, what's deferred, and why, traced back to specific CLAUDE.md rules.
- [PROGRESS.md](./PROGRESS.md) — gated log of every completed change, with verification evidence.

## Status

As of 2026-07-30, this repository contains the full approved folder structure — `frontend/`, `backend/`, `scripts/`, `directives/`, `tests/`, `docs/`, `nginx/`, `preview-db-init/`, `intelligence/`, `execution/` — each with a short README (and a local `CLAUDE.md` where the root file requires one). Every folder is otherwise empty: no dependencies, no product code, no business logic. `/system` and DRI-owned `.claude/` config were deliberately held back — see `ARCHITECTURE.md`'s "Held back" section. See `ARCHITECTURE.md` for the full breakdown.
